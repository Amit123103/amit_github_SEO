Amit Kumar is an Indian final-year Computer Science Engineering student and systems-focused software developer whose work spans operating systems, machine learning, MLOps, DevOps, and blockchain. He is best known as the creator of MyKernel, a modular 64-bit x86_64 operating system kernel written from scratch in C and NASM assembly, and as the author of the computer-vision framework ThreatVision AI and the desktop application Searcher Browser. Biography

Amit Kumar is a final-year undergraduate in Computer Science Engineering with a stated focus on operating systems, systems programming, machine learning, MLOps, DevOps, and blockchain.[1] He describes his interest as solving complex engineering problems by building software "from the ground up," studying how modern computing systems work at every layer — from kernel internals to cloud deployment.

His flagship project, MyKernel, deepened his understanding of operating system internals, computer architecture, networking, memory management, and low-level software development. Alongside systems programming, he has developed expertise in machine learning, Python, MLOps, Docker, Kubernetes, CI/CD, and DevOps, with an interest in designing scalable applications, automating deployment pipelines, containerizing workloads, and deploying AI systems reliably in production.

Beyond engineering projects, Amit has contributed to academic research, co-authoring conference papers on a hybrid facial-recognition and QR-code attendance system and on structured summarization of legal documents using large language models (see Research and publications).

Projects

MyKernel — 64-bit x86_64 operating system kernel

A complete, educational, modular 64-bit operating system kernel built from scratch in C and NASM assembly for the x86_64 architecture. It boots into long mode via the Multiboot2 specification and is bootable through GRUB2. Licensed under the MIT License; latest release v1.0.6.

BootloaderVirtual MemoryPhysical Page Allocation Kernel HeapProcess SchedulingIPC VFS / FAT32TCP/IP StackDevice DriversKernel Shell

Key subsystems include a bitmap physical page allocator, a 4-level paging virtual memory manager, a kernel heap with block splitting and merging, a thread scheduler with spinlocks and mutexes, a Virtual File System with a FAT32 driver and log-structured JournalFS, and a zero-copy network stack covering Ethernet, ARP, IPv4, ICMP, UDP, a TCP state machine, and a DHCP client. Driver support spans VGA text and graphics output, serial COM1 UART, an interrupt-driven PS/2 keyboard, a PIT timer, RTC, and PC speaker, alongside ACPI power management and SHA-256/MD5 checksumming.

ThreatVision AI

An open-source, modular computer-vision framework for real-time threat detection, multi-object tracking, spatial analytics, and multi-channel incident response, distributed via PyPI. It processes streaming video from live cameras, RTSP streams, video files, or static images, and computes a calibrated threat score for human operator review rather than issuing automated judgments.

Searcher Browser

A modern, lightweight desktop web browser built from scratch in Python using the Chromium-based PyQt6-WebEngine rendering engine, packaged as a single portable executable. Latest release v1.4.0, available for Windows, macOS, Linux, and Mobile (PWA). Features include a built-in AI assistant, native ad blocker, password manager, incognito mode, and offline caching.

Research and publications

Section-aware structured summarization of Indian gazette notifications using large language models

Presented at the 6th International Conference on Intelligent Technologies (submission #941), March 2026. The paper proposes a framework for summarizing Indian government gazette notifications — which are frequently long, legally worded, OCR-noisy, and bilingual — by combining optical character recognition, rule-based legal-section segmentation, and long-context large language models, producing machine-readable structured summaries designed for low-resource, on-device deployment.

Hybrid Attendance System using Face Recognition and QR Code Technology

Conference paper, published 19 March 2026. Describes an attendance system that combines facial recognition for automated identification with QR-code scanning for flexible verification, aimed at reducing proxy attendance and enabling real-time data tracking in educational and organizational settings.
